# Meesaq Al Amana Website

Official website for **Meesaq Al Amana**, a UAE-focused procurement and sourcing company that helps businesses source industrial electronics, automotive parts, wholesale goods, and other products with worldwide delivery support.

## Overview

This project is a static business website designed to:

* Showcase procurement and sourcing services
* Present product sourcing categories
* Publish SEO-focused sourcing and procurement blogs
* Improve online visibility through structured metadata and technical SEO
* Provide a lightweight, fast-loading browsing experience

The site is built using simple front-end technologies for fast deployment and easy maintenance.

# Getting Started

## Clone the Repository

```bash
git clone <repository-url>
cd meesaq-site
```

## Run Locally

Since this is a static website, you can run it using any local development server.

### Option 1 — VS Code Live Server

1. Install the **Live Server** extension in Visual Studio Code
2. Open the project folder
3. Right-click `index.html`
4. Click **Open with Live Server**

### Option 2 — Python HTTP Server

```bash
python -m http.server 8000
```

Then open:

```txt
http://localhost:8000
```

# Deployment

The project is configured for deployment using GitHub Pages.

## GitHub Pages Setup

1. Push the repository to GitHub
2. Open repository settings
3. Go to **Pages**
4. Select the main branch
5. Save settings

## Custom Domain

The project uses a custom domain configured through the `CNAME` file.

Example:

```txt
www.meesaqalamana.com
```
